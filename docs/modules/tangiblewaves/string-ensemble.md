# STRING ENSEMBLE

[[img|modules/images/STRING_ENSEMBLE.png|400]]

[[https://www.tangiblewaves.com/store/p242/STRING_ENSEMBLE.html | View Product Page]]

The STRING ENSEMBLE is a polyphonic string synthesizer inspired by the lush sound of electronic
string machines from the 1970s.

The module can be played via **MIDI** or **CV/Gate**. In CV mode,
incoming control voltages are quantized to the selected scale and
automatically expanded into chords.

## Features

-   24 voices, full polyphonic
-   MIDI input
-   CV/Gate input with automatic chord generation
-   Major / Minor scale selection for CV control
-   different chord types/inversions for CV control
-   Two oscillators per voice
-   Adjustable oscillator detune
-   Optional sub oscillator
-   Optional octave oscillator
-   Stereo Chorus / Ensemble effect
-   Stereo Phaser
-   CONFIG button for additional functions
-   Automatic storage of global settings

# Connections

| Connection | Function |
|------------|----------|
| CV IN | 1 V/Oct control voltage input |
| GATE IN | Triggers chords in CV mode |
| CV2 IN | Chord type |
| IMDI IN | IMDI / MIDI input |
| AUDIO L | Left audio output |
| AUDIO R | Right audio output |
| GATE OUT | MIDI Gate output (high as long as any MIDI note is pressed) |

**Please note:** The GATE OUT is the 5th socket on the output side; in the first batch of frontpanels, this is not marked explicitly, but (wrongly) included in the MULT section. But the GATE OUT is active in any case.

# Controls

## Oscillators

| Control | Function |
|---------|----------|
| PITCH | Base note for CV mode. Has no effect in MIDI mode. |
| SPREAD | Adjusts the detune between both oscillators. |
| VIB RATE | Vibrato speed. |
| VIB DEPTH | Vibrato intensity. |
| ATTACK | Attack time of the amplifier envelope. |
| RELEASE | Release time of the amplifier envelope. |

## CV Chord Mode

| Control | Function |
|---------|----------|
| CHORD knob | Selects the generated chord type. |
| MAJ / MIN | Selects the active scale, major or minor. |
| BASS | Adds a bass note one octave below the chord root. |

| Control | Function |
|---------|----------|
| RATE | Chorus / Ensemble modulation speed. |
| DEPTH | Chorus / Ensemble modulation depth. |
| MIX | Dry / Wet balance. |

## Phaser

| Control | Function |
|---------|----------|
| Phaser RATE | Phaser modulation speed. |

# CV/Gate Mode

In CV mode, a single CV/Gate pair controls complete chords instead of
individual notes.

The incoming CV is quantized to the selected scale before chord
generation.

CV2 controls the chord type, parallel to Chord knob 

## Chord Types

| Type | Description |
|------|-------------|
| Triad | Standard three-note chord. |
| Diminished | Suspended, open sounding chord. |
| Augmented | Bright, wide sounding chord. |
| Seventh | Four-note chord with added harmonic richness. |
| Power | Root, fifth and octave. |

### Notes

-   1 V/Oct compatible CV input
-   Incoming CV is quantized to the selected scale
-   Chords change immediately while the gate is active
-   The Pitch control transposes the complete scale chromatically

# CONFIG Functions

Hold the **CONFIG** button while turning a control to access additional functions.

| Control | CONFIG Function |
|---------|-----------------|
| Pitch | Master Tune |
| Detune | Oscillator Mode |
| Phaser Feedback | Phaser Stereo Width |

## Oscillator Mode

| Knob Position | Function |
|---------------|----------|
| Full left | no sub oscillator, both oscillators same pitch plus detune |
| Left of Centre | Increased suboscillator mix |
| Centre | Suboscillator full level |
| Right of Centre | second oscillator 1 octave higher, reduced suboscillator mix |
| Full right | no suboscillator, second oscillator 1 octave higher |

## Master Tune

Adjusts the global tuning reference (A4).

## Phaser Stereo Width

Adjusts the stereo spread of the phaser effect.
